# lookpup
믿고 맡기는 우리 동네 펫시터 매칭 사이트 - 봐주개

## Tech Stack

- Next.js (App Router) / React / TypeScript
- Tailwind CSS + shadcn/ui
- React Hook Form + Zod
- TanStack Query v5
- Zustand
- Supabase (Auth/DB) via `@supabase/ssr`
- 카카오맵 API (`react-kakao-maps-sdk`)
- PortOne 결제 API (`@portone/browser-sdk`)
- Vercel 배포

## Getting Started

```bash
npm install
cp .env.local.example .env.local # 값 채우기
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
